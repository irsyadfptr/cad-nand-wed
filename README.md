# Admit Two — our 3rd anniversary

A small site for Nanda, built for 25 December 2026.

- **Hero ticket** — serial number is the live count of days married; the stub counts down to the anniversary.
- **Every ticket we kept** — the story, one ticket per chapter.
- **The ticket counter** — a 5-question quiz; each right answer pays 30 tickets, 150 redeems the letter.
- **Our film** — drop a video at `public/video/anniversary.mp4` and the player appears.

## Editing

All words, photos, quiz questions and the letter live in `src/content.js`.
Lines marked `TODO` are placeholders.

## Run

npm install

npm run build
